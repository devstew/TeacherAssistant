# Журнал спостережень асистента вчителя

Веб-застосунок (React + TypeScript, PWA) замість паперового бланку спостережень:
розклад уроків дитини, швидке заповнення бланку на телефоні, експорт документів
і дашборд динаміки навчання й поведінки.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # юніт-тести (Vitest)
npm run build      # перевірка типів + збірка в dist/ (зі service worker для офлайну)
```

## Деплой (Vercel)

Vercel визначає Vite автоматично; налаштування — у `vercel.json`
(build `npm run build`, output `dist`, `sw.js` і маніфест без кешування).
Роутинг у застосунку хешовий (`/#/dashboard`), тож переписування шляхів не потрібне.

```bash
git push                       # Vercel збере гілку автоматично
# або разово вручну:
npx vercel --prod
```

Змінні оточення: за потреби `VITE_ENABLE_DEMO=1`, щоб показати демо-дані на проді
(за замовчуванням вимкнені). Збірка тягне `xlsx` із cdn.sheetjs.com — потрібен доступ
до мережі під час встановлення залежностей.

## Демо-дані

**Вимкнені за замовчуванням.** Щоб увімкнути: `VITE_ENABLE_DEMO=1 npm run dev` — тоді
з'являються кнопки на стартовому екрані та в «Налаштування → Дані й резервна копія».
Створюються два профілі:

- **Демо: Андрій К., 4-А** — поточний навчальний рік: розклад і спостереження від 1 вересня
  до сьогодні, останній навчальний день заповнений лише до 2 уроку, підсумок дня порожній.
  Є дні хвороби, день із частковою відсутністю, додатковий корекційно-розвитковий урок,
  теми, коментарі до уроків і примітки. Для щоденного сценарію.
- **Демо: Софія М., 3-Б** — вересень–листопад минулого року з покращенням у листопаді.
  Для дашборду, порівняння місяців і аналітичного звіту.

Файли для перевірки імпорту з Human лежать у `demo/`
(`human-oblik-vidviduvannia.xlsx` — відсутності за поточний місяць для «Андрій К.»,
`human-ktp-matematyka.xlsx` — теми з датами на найближчі дні). Перестворити їх:
`node scripts/make-demo-files.mjs`.

## Що вміє

- **Сьогодні** — уроки дня з тижневого шаблону: предмет, час, тема, «н», статус заповнення.
- **Урок** — бланк як на папері: навчальна діяльність, увага, емоційний стан, поведінка,
  взаємодія з вчителем і асистентом (рівень допомоги, адаптації), хвилини уваги, коментар.
  Автозбереження, копіювання з попереднього уроку.
- **Підсумок дня** — комунікативні та соціальні навички, примітка.
- **Розклад** — тижневий шаблон, дзвінки, канікули, імпорт файлів з Human.
- **Дашборд** — індекси навчання й поведінки, тренди, категорії, теплова карта всіх пунктів
  (% уроків), розподіл допомоги, розрізи за предметами й номером уроку, текстові висновки
  на кшталт «У листопаді дитина показала кращі показники, ніж у жовтні…».
- **Експорт** — щоденний аркуш і журнал за період (PDF/DOCX, копія бланку),
  аналітичний звіт (PDF/DOCX з графіками), сирі дані (XLSX), резервна копія (JSON).

## Human

Публічного API в Human немає (інтеграції лише закриті: Мрія, АІКОМ, AR Book, Microsoft, Zoom),
через «Мрію» дані третім сторонам недоступні. Тому:

- розклад вноситься один раз у застосунку (Human не експортує розклад);
- відсутності — імпорт Excel «Облік відвідування» / «Експорт відвідуваності в Excel»;
- теми — імпорт КТП з Excel (той самий файл, що імпортують у Human).

Розбір файлів — евристичний (`src/integrations/human/fileImport/`), з попереднім переглядом.
**Перевірте його на справжньому (знеособленому) експорті зі школи.** Усе проходить через
`HumanDataProvider` — офіційне API, якщо Human його надасть, підключається як `ApiProvider`
(через серверний проксі, щоб не зберігати ключі в браузері).

## Метрики

Схема бланку — `src/domain/formSchema.ts` (id пунктів, полярність +1/−1/0, ваги, групи
взаємовиключення). У базі зберігаються лише позначки; показники рахуються на льоту
(`src/domain/scoring.ts`, `aggregate.ts`, `insights.ts`), тож зміна ваг у налаштуваннях
перераховує всю історію.

- Частота пункту = уроки з позначкою ÷ уроки із заповненою категорією (уроки з «н» не рахуються).
- Індекс категорії = 50 + 50 × (частка позначених позитивних − частка позначених негативних), 0–100.
- Самостійність = 100 × (1 − підтримка асистента); індекс навчання й поведінки — середні категорій.

## Дані

Усе зберігається локально в IndexedDB цього браузера (Dexie) і нікуди не надсилається.
Для перенесення на інший пристрій і для страховки — JSON-резервна копія в налаштуваннях.
